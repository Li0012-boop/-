# 趣味五子棋 · Gomoku

一个纯前端、单文件的趣味五子棋小游戏。双击 `趣味五子棋.html` 即可在浏览器中直接游玩，无需安装任何依赖，也无需联网。

## ✨ 功能

- **双人对战**：黑白双方轮流落子，五子连珠即胜
- **人机对战**：与电脑对战，支持**简单 / 困难**两档难度
  - 简单：启发式评分 + 随机策略，适合新手
  - 困难：α-β 剪枝的负极大（Negamax）搜索，进攻防守较强
- **悔棋**：一键撤回上一步
  - 双人模式：撤回一步
  - 人机模式：连同一同撤回电脑的一步
- **橙色木质棋盘**：带木纹质感、星位的标准 15×15 棋盘
- **操作按钮位于右侧面板**：模式切换、难度切换、悔棋、新游戏
- **开始界面**：开局前选择游戏模式（双人 / 人机）与难度（简单 / 困难）

## 🎮 如何游玩

1. 用浏览器打开 `趣味五子棋.html`
2. 在开始界面选择 **双人对战** 或 **人机对战**，以及人机难度
3. 点击「开始游戏」
4. 在棋盘上点击落子，五子连珠（横、竖、斜）即获胜

## 🚀 部署到 GitHub Pages（在线演示）

本文件为纯静态 HTML，可直接托管：

1. 新建 GitHub 仓库，把 `趣味五子棋.html` 和 `README.md` 上传
2. 仓库 **Settings → Pages** → Source 选择 `main` 分支 / `root`
3. 保存后即可通过 `https://<你的用户名>.github.io/<仓库名>/趣味五子棋.html` 在线游玩

## 🧠 AI 说明（简要）

- 棋盘为 15×15，黑方（玩家）先行
- 评估函数按「连子数 × 开放性（活/眠）」给每个方向打分
- 困难模式在候选点（已有棋子相邻位置）上进行 α-β 负极大搜索，深度 3
- 全部逻辑内置于单文件，无外部依赖
